# CS50x Week 9 — Flask 🐍

This repository contains my work on **Week 9 of Harvard's CS50x: Introduction to Computer Science**, focused on building web applications using Flask, Python, SQL, and HTML.

## Projects

### 1. Birthdays 🎂

A Flask web application that allows users to add birthdays and view saved entries.

**Features**
- Form-based birthday submission
- Input validation
- SQLite database storage
- Display of saved birthdays using Jinja templates

**Technologies:** Python, Flask, SQLite, HTML, CSS

### 2. Finance 📈

A stock-trading simulator that combines backend programming, database queries, and web interfaces.

**Features implemented**
- User registration and authentication
- Stock quote lookup
- Buying and selling shares
- Portfolio and cash balance display
- Transaction history
- Additional cash-deposit functionality under development/testing

**Technologies:** Python, Flask, SQL, SQLite, HTML, CSS, Jinja

## Key Concepts Practised

- Flask routes and HTTP GET/POST requests
- HTML forms and server-side validation
- SQL queries and database operations
- Password hashing and user sessions
- Jinja templating
- Portfolio calculations and transaction records
- Debugging and connecting frontend forms to backend logic

## Learning Outcome

These exercises helped me understand how Python, a web framework, and a database work together to create interactive applications. They also gave me practical experience handling user input, storing records, validating transactions, and organizing application logic.

**Part of my ongoing CS50x learning journey.** 🚀
